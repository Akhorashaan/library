# Отслеживание серий и десктопная раскладка — 29.09.2026

## Поведение

- У каждой серии есть «Не следить» / «Следить снова». По умолчанию открыт список «Слежу»; доступны «Не слежу» и «Все серии».
- Верхние итоги относятся к отслеживаемым сериям. Фильтры полноты учитывают выбранный список и поиск.
- Книги и проверенный состав сохраняются. Настройка хранится в SQLite отдельно, в `series_preferences`, и не сбрасывается при обновлении справочника.
- `PUT /api/series/preference` принимает название и булево `following`. `GET /api/series` возвращает настройку вместе с полнотой; для существующих серий по умолчанию `true`.
- Прямая ссылка из книги открывает серию, даже если пользователь перестал за ней следить. После переключения есть «Отменить»; при ошибке запрос не скрывает карточку.

## Интерфейс

Убрано ограничение основной области в 1180 px. Каталог на десктопе показывает непрерывную сетку карточек с серией внутри каждой карточки; на телефоне остаются разделители групп. Поиск и сортировка собраны в одну панель. Обложки и названия на десктопе крупнее. В разделе серий на широком экране фильтры расположены сбоку; на телефоне — компактный список. Примечания и источники перенесены в раскрываемые подробности, длинные списки недостающих книг можно развернуть. Карточка книги и список чтения используют колонки.
