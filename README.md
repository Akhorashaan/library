# Картотека

Домашняя библиотека: каталог, добавление книг по ISBN или штрих-коду с обложки, списки чтения. PWA, ставится на домашний экран, работает офлайн. Крутится на своём железе, данные никуда не уезжают.

## Запуск

```bash
npm install
npm run seed     # необязательно: 14 книг, чтобы было что разглядывать
npm run dev
```

Интерфейс — http://localhost:5183, API — http://localhost:3017.

Ключ Google Books кладётся в `.env` (см. `.env.example`). Без него каскад работает, но теряет один источник: анонимная квота Google общая на IP-адрес и обычно уже исчерпана кем-то другим.

### Сборка

```bash
npm run build && npm start
```

В проде тот же процесс отдаёт и API, и статику — один порт.

### Docker

Для сервера в интернете: [развёртывание в облаке](docs/CLOUD.md) — VPS, домен, HTTPS, пароль и перенос существующей библиотеки.

```bash
docker compose up -d --build
```

Открыть http://localhost:5183. Контейнер собирает production-интерфейс и отдаёт его вместе с API. Другой внешний порт можно задать через `LIBRARY_PORT` в `.env`; ключ `GOOGLE_BOOKS_KEY` также берётся оттуда.

База и обложки подключены из папки `data/` на компьютере и сохраняются при пересоздании контейнера. Не запускайте одновременно локальный сервер и контейнер с этой базой.

Политика `restart: always` поднимает приложение после сбоя или перезапуска Docker. На Windows Docker Desktop должен запускаться при входе пользователя в систему: Settings → General → Start Docker Desktop when you sign in to your computer. Это запуск после входа в Windows, а не до него.

```bash
docker compose ps             # состояние и healthcheck
docker compose logs --tail 50 # последние логи
docker compose up -d --build  # обновить после изменения кода
docker compose down          # выключить до следующего ручного запуска
```

### Открыть с телефона

В Docker HTTPS уже обслуживает Caddy: **https://192.168.0.117:5184**. Телефон должен быть в той же домашней сети. Адрес компьютера задаётся через `LIBRARY_HOST`, HTTPS-порт — через `LIBRARY_HTTPS_PORT` в `.env`. При смене адреса выполните `docker compose up -d`; Caddy выпустит новый сертификат. Удобнее закрепить адрес компьютера в настройках DHCP роутера.

Для Android один раз установите локальный корневой сертификат:

1. Скачайте [kartoteka-ca.crt](http://192.168.0.117:5183/local-ca.crt) на телефон.
2. В настройках телефона найдите «Установить сертификат» → «Сертификат ЦС» (CA). Обычно это раздел «Безопасность» → «Дополнительные настройки» → «Шифрование и учётные данные». Выберите скачанный файл. Названия пунктов зависят от производителя; [справка Google](https://support.google.com/pixelphone/answer/2844832).
3. Откройте HTTPS-адрес в Chrome и разрешите доступ к камере на странице сканирования.

При первом развёртывании на другом компьютере после `docker compose up -d --build` экспортируйте публичный сертификат:

```bash
docker compose cp https:/data/caddy/pki/authorities/local/root.crt data/https-public/local-ca.crt
```

Caddy автоматически обновляет сертификаты сайта. Корневой сертификат и закрытые ключи хранятся в Docker volume `caddy_data`; сохраняйте его при пересоздании контейнера. Не используйте `docker compose down -v`, если хотите сохранить доверие уже настроенных телефонов. Для скачивания доступен только публичный сертификат из `data/https-public/`.

#### Доступ при разработке

`npm run dev` слушает на всех адресах, так что каталог открывается по адресу машины в локальной сети — Vite печатает его при старте (`Network: http://192.168.…:5183`).

Но **камеру браузер отдаёт только в защищённом контексте**: HTTPS или `localhost`. По `http://192.168.…` сканер работать не будет — это правило браузера, а не приложения. Поэтому там же есть ручной ввод ISBN и разбор фото из галереи: оба идут через тот же детектор и тот же каскад.

Чтобы проверить живую камеру:

```bash
npm run dev:https
```

HTTPS-интерфейс запускается на порту **5184**: `https://<адрес компьютера>:5184`. API работает на порту 3017. Если порт интерфейса занят, запуск сообщит об ошибке вместо перехода на другой порт. Телефон покажет предупреждение о самоподписанном сертификате — его нужно принять («Дополнительно» → «Перейти на сайт»). После этого origin считается защищённым и камера включается.

На iOS Safari к самоподписанным сертификатам строже: просмотр он разрешит, а в камере может отказать, пока сертификат не установлен в профиль и не отмечен как доверенный. Если возиться не хочется, для Android есть путь без сертификатов вовсе: `chrome://flags/#unsafely-treat-insecure-origin-as-secure`, вписать туда `http://192.168.…:5183` и включить.

Установка на домашний экран как PWA потребует уже валидного сертификата — самоподписанный для этого не годится.

### Данные

Три таблицы: `books` (произведение и издание), `copies` (физический экземпляр: состояние, кому отдан), `reading` (статус, прогресс, заметка). Разделение нужно потому, что дома бывает два издания одной книги, а «кому я её отдал» относится к томику, а не к тексту. Наружу API отдаёт один плоский объект — клиенту про джойны знать незачем.

### Как искать в каталоге

Поиск по автору, названию и издательству — FTS5, понимает префиксы и любой регистр. Поверх него фильтры: статус чтения, «не дома», жанр, автор, издательство. Значения фильтров приходят со счётчиками, поэтому выбрать заведомо пустой нельзя.

Сортировка — по автору, названию, году или дате добавления. От неё же зависит разбивка на секции: по автору и названию каталог делится буквенными разделителями, как картонки в каталожном ящике, по году — годами, недавно добавленные идут сплошным списком.

Порядок «по автору» — по **фамилии**: «Варлам Шаламов» стоит под Ш, а не под В. Источники пишут имя и так и эдак, поэтому ключ сортировки вычисляется при записи и хранится отдельным полем.

Всё лежит в `data/kartoteka.db`, обложки — в `data/covers/`. Бэкап — это копия папки `data/`.

### Когда ISBN никто не знает

Такое бывает с самиздатом, старыми и подарочными изданиями. Штрих-код не пропадает: он откладывается в стопку **«на разбор»**, а в каталоге появляется напоминание, пока стопка не пуста.

Там же его можно разобрать: попробовать поиск заново (базы пополняются, и через месяц попытка имеет смысл), завести книгу руками короткой формой или просто убрать. Заметка «синий сборник стихов с дачи» помогает вспомнить, о чём вообще речь.

Одинаковые в стопке не копятся: ключ таблицы — сам ISBN, поэтому повторный скан не добавляет строку, а увеличивает счётчик попыток. Когда книга заводится в каталог, её ISBN уходит из стопки сам.

### Откуда берутся метаданные

Каскад собирает запись из двух слоёв, потому что лучшие источники для них разные:

- **произведение** (название, автор, аннотация, жанр, обложка) — LiveLib, затем K10plus: они дают кириллицу, а не библиотечную транслитерацию;
- **издание** (год, страницы, переплёт) — Google Books, OpenLibrary, LoC: они отвечают именно на запрошенный ISBN, тогда как LiveLib склеивает все издания в одну карточку и год у него случайный.

На карточке книги видно, какой источник дал какое поле.

Замерить покрытие на своей полке:

```bash
npm run probe -- 9785699754670 9785389074354
npm run probe -- --file my-shelf.txt
```
